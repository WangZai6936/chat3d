# 连续旋转薄壳、端盖与检查反馈（v51）

针对 v50 实测的环堆灯罩、底座意外开口和重复读取问题：

- lathe 保留旧默认，新增 capStart/capEnd；生成实心端盖，不靠手写零半径端点。
- lathe 新增 wallThickness，生成连续内外壁和两端环形端缘；保留真实开口。厚度为径向差，不等于各曲面的法向恒定壁厚。不支持与实心端盖混用。
- tube 改用连续旋转内外侧面，保留硬边端缘，避免挤出圆环的侧面分面法线。
- 同组件轴对齐实体盒的共面重叠检查（最多256盒/6条线索），提示近景核对闪烁黑缝，正常相邻面不报警。非全模型碰撞检测。
- 所有场景新增旋转体开口检查线索；已命名壳体的多级管环也提示连续建模。线索不强行判错，不封闭本来就应开放的结构。
- 编辑结果立即带几何警告。重复相同版本/相同设计的整体检查和相同部件查询不再重复大结果；版本或设计变化会重查。
- 无效几何批次给出操作号、部件号和具体参数错误，整批原子拒绝，便于局部修正。

回归检查覆盖：闭合网格边界配对、薄壳开口未被封死、内外壁及法线、非法厚度、端盖互斥、旧项目保留、导入导出参数保留、重复检查与失败定位。真实质量与用量改善必须以新一轮实际生成结果为准，不能以这些单测代替。
